# Agentic QA Platform

An AI-driven multi-agent testing system designed to automate end-to-end software quality assurance.

## 🚀 Overview
This project simulates a production-grade Agent-based QA system used in internal environments.

It automates:
- Requirement parsing
- Test case generation
- Execution & validation
- Failure analysis
- Regression enhancement

## 🧠 Architecture
PRD → Parsing Agent → Test Generation → Execution Agent → Analysis → Feedback Loop

## ⚙️ Tech Stack
- Python
- Playwright
- REST API Testing
- LLM Agent Framework
- CI/CD (GitHub Actions)

- 60% reduction in manual QA effort
- 50% earlier bug detection
